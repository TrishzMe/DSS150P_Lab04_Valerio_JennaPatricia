# baseline — the original group project (reference only)

`original/` holds byte-identical copies of the Predictive Analytics group project that this
laboratory reproduces. They are kept for attribution and traceability only; they are **not**
part of the executable pipeline and are never modified.

| File | Description |
|---|---|
| `original/Predictive_Final_Project_code.ipynb` | Original notebook with its saved outputs (source of `metadata/expected_metrics.json`) |
| `original/paper.md` | Original project paper |

**Attribution:** S. Grino, B. J. Perez and J. P. Valerio, *Predicting PM2.5 Air Quality
Exceedances Using Machine Learning: A Co-Pollutant Chemistry Approach*, Predictive Analytics
group project, School of Data Science, Mapúa University, 2026. This repository reuses its
problem statement, target definition, feature definitions, preprocessing steps, model families,
hyperparameters and reported metrics, as allowed by section 4.1 of the laboratory brief. The
engineering implementation (the pipeline, tests and documentation) is individual work.
